# SaaS 서비스 기획서: Rootin (루틴)

## 1. 프로젝트 개요

### 1.1. 서비스명

**Rootin (루틴)**

### 1.2. 서비스 배경 및 목적

| 구분 | 내용 |
|---|---|
| **배경** | 자기 계발 및 학습에 대한 관심 증가로 학습 기록 서비스 수요 증가. 기존 서비스는 단순 기록 기능에 그쳐 지속적인 참여 유도에 한계 존재 |
| **목적** | 학습 기록의 재미와 동기 부여 강화, 지속 가능한 학습 습관 형성 지원 |
| **서비스명 의미** | `Root(뿌리)` + 진행형 `-ing` 합성어. 학습의 뿌리를 내리고 성장하는 과정을 의미. `Routine(루틴)`과 발음 유사하여 매일 꾸준한 학습 습관 강조 |

## 3. 차별화 포인트 (USP)

| 핵심 가치 | 내용 |
|---|---|
| **게임화(Gamification)** | 학습 활동을 통해 가상의 식물을 키우고 보상을 얻는 경험 제공 |
| **내재적 동기 부여** | 외부 강제나 알림이 아닌, 식물이 자라는 모습을 보며 스스로 학습을 이어가고 싶게 만드는 구조. "오늘 안 쓰면 식물이 안 자란다"는 자발적 긴장감 형성 |
| **성장의 시각화** | 화분 레벨업, 식물 성장 단계, 잔디 그래프 등을 통해 학습 노력이 눈에 보이는 결과로 축적됨. 꾸준함이 형태로 남는 경험 제공 |
| **개인화된 학습 공간** | 나만의 화분과 정원으로 꾸며지는 학습 공간. 학습 주제와 기록이 쌓일수록 정원이 성장하며 나만의 고유한 공간이 완성됨 |

## 4. 주요 기능 정의

### 4.1. Home

| 기능 | 설명 |
|---|---|
| **Home** | 로그인한 사용자의 개인 페이지. 나의 정원, 나의 TIL, 계정 관리 등 주요 메뉴 |
| **랜딩 페이지** | 비로그인 사용자에게 보여주는 서비스 소개 페이지. 로그인/회원가입 외 접근 불가 |

### 4.2. TIL (Today I Learned) 작성 및 관리

| 기능 | 설명 |
|---|---|
| **시리즈 기반 관리** | Velog 시리즈 형식 차용. 각 시리즈는 하나의 화분과 연동 |
| **본문 에디터** | 제목 + 본문 에디터 구성. 이미지, 글, 링크 등 다양한 콘텐츠 지원 |
| **화분 선택** | TIL 작성 시 어느 화분(폴더)에 기록할지 선택 가능 |
| **태그** | 태그 입력을 통해 해시태그 추가 |
| **템플릿** | 범용 TIL 템플릿 제공 또는 자신만의 템플릿 등록 가능 |
| **임시저장** | 작성 중인 내용 임시저장 후 이어서 작성 가능 |

### 4.3. 정원 (학습 주제 관리) 및 식물 성장 시스템 (Gamification)

| 기능 | 설명 |
|---|---|
| **화분 생성** | 학습 주제별 화분(폴더)을 생성하고 씨앗을 심어 식물 키우기를 시작 |
| **물주기** | TIL 작성 시 자동으로 해당 화분에 물주기 실행. 물을 줄수록 식물이 성장하고 화분 경험치 누적 |
| **경험치** | TIL 작성 시 화분에 쌓이는 수치. 경험치가 누적될수록 화분 레벨이 상승함 |
| **화분 레벨** | TIL 작성 및 학습 활동량에 따라 한계 없이 성장. 레벨 구간마다 화분 외형이 단계적으로 업그레이드됨 (예: 브론즈 → 실버 → 골드 → 플래티넘 → 다이아몬드) |
| **식물 성장 단계** | 씨앗 → 새싹 → 잎 → 개화 → 만개 (화분 레벨 변화량 기반) |
| **화분 내부 정보** | TIL 개수, 성장 진도, 식물 성장 단계, 연속 기록일 그래프 |
| **수확하기** | 사용자가 원하는 시점에 현재 식물을 수확할 수 있음. 수확된 식물은 식물도감에 등록되며 수확 후 새 씨앗을 심어 다시 시작할 수 있음 |
| **정원 장식** | 수확된 화분이 정원에 전시됨. 배경 변경 가능 |

### 4.4. 성장 시각화 (대시보드)

| 기능 | 설명 |
|---|---|
| **잔디 그래프** | GitHub 방식으로 날짜별 TIL 작성 여부 시각화. 글자 수에 따라 색상 농도 표현. 연속 기록일(스트릭) 함께 표시로 동기 부여 강화 |
| **주간 현황** | 주간 TIL 작성 현황 |
| **관심사 분포 및 변화** | 화분별 TIL 개수를 통해 현재 학습 관심사 분포를 확인하고, 시기별 주요 학습 주제 변화 흐름을 시각화 |
| **개인 통계** | 전체 TIL 수, 총 작성 글자 수, 누적 학습일 등 나의 학습 성장 지표 제공 |

### 4.5. 동기부여 시스템

| 기능 | 설명 |
|---|---|
| **포인트** | 오늘의 목표 달성 시 포인트 지급. AI 기능 활용에 사용 |
| **경험치 가중치** | 글자 수 × 0.2 × 1.n (n = 연속 작성 일수) 공식으로 산정. 글자 수가 많을수록, 연속으로 작성할수록 더 많은 경험치 획득 |
| **식물도감** | 수확한 식물들을 모아 컬렉션으로 관리. 획득한 식물 종류 확인 가능 |
| **랜덤 식물** | 4.2에서 언급된 씨앗 심기는 랜덤으로 식물 종류가 결정됨. 일반종 90% / 희귀종 10% 확률로 획득하여 키우는 재미 추가 |

### 4.6. AI 학습 도구

| 기능 | 설명 |
|---|---|
| **TIL 요약** | 작성된 TIL을 분석하여 핵심 내용 자동 요약 |
| **복습 문제 생성** | 작성된 TIL을 기반으로 복습 문제 생성. 질문 개수 설정 가능 |
| **결과 관리** | 생성된 AI 결과 저장 및 삭제 가능 |

### 4.7. 회원 / 인증

| 기능 | 설명 |
|---|---|
| **회원가입/로그인** | 이메일 기반 가입 및 로그인 |
| **소셜 로그인** | 구글 소셜 로그인 지원 |
| **JWT 인증** | JWT 기반 토큰 인증으로 안전한 세션 관리 |
| **계정 관리** | 닉네임, 소개, 프로필 이미지, 비밀번호 수정 |

## 5. 기술 아키텍처

### 5.1. 프론트엔드 (Frontend)

| 기술 분류 | 상세 기술 | 설명 및 선정 이유 |
|---|---|---|
| **프레임워크** | `React 18+` (TypeScript) | 컴포넌트 기반 개발로 재사용성 및 유지보수 용이. 정적 타입 검사를 통한 코드 안정성 향상. |
| **빌드 도구** | `Vite` | 빠르고 가벼운 개발 서버 및 번들링. 개발 생산성 극대화. |
| **상태 관리** | `Zustand` 또는 `Recoil` | 가볍고 직관적인 전역 상태 관리. React Context API의 한계 보완. |
| **스타일링** | `Tailwind CSS` | 유틸리티 우선 CSS 프레임워크. 빠른 UI 개발 및 일관된 디자인 시스템 구축. |
| **에디터** | `Tiptap` | 노션 스타일 블록 기반 에디터. React 친화적이며 이미지, 글, 링크 등 다양한 콘텐츠 블록 지원. |
| **라우팅** | `React Router DOM` | SPA에서 클라이언트 측 라우팅 구현. |
| **HTTP 클라이언트** | `Axios` 또는 `Fetch API` | 백엔드 API와의 효율적인 통신. |
| **폼 관리** | `React Hook Form` | 복잡한 폼 로직을 간결하게 관리. 유효성 검사 및 성능 최적화. |
| **차트/그래프** | `Chart.js` 또는 `Recharts` | 학습 통계 및 성장 그래프 시각화. |

### 5.2. 백엔드 (Backend)

| 기술 분류 | 상세 기술 | 설명 및 선정 이유 |
|---|---|---|
| **프레임워크** | `Spring Boot 3.x` (Java 17+) | 강력한 생태계와 높은 생산성. |
| **데이터베이스** | `MySQL 8.0` | 안정적이고 널리 사용되는 관계형 데이터베이스. |
| **ORM** | `Spring Data JPA` (Hibernate) | 객체-관계 매핑을 통한 생산성 향상. |
| **동적 쿼리** | `Querydsl` | 복잡한 조건 검색 및 동적 쿼리 타입 안전하게 작성. 대시보드 통계 집계에 활용. |
| **빌드 도구** | `Gradle` | 유연하고 강력한 빌드 시스템. |
| **인증/인가** | `Spring Security` + `JWT` | 사용자 인증 및 권한 관리. REST API에 적합한 토큰 기반 인증. |
| **API 문서화** | `Swagger UI` | 전 엔드포인트 자동 문서화. 프론트/백 협업 시 API 명세 공유 및 직접 테스트 가능. |
| **유효성 검사** | `Spring Validation` | 사용자 입력 데이터의 서버 측 유효성 검사. |
| **스케줄링** | `Spring Scheduler` | 일일 퀘스트 초기화 등 주기적인 백그라운드 작업 처리. |
| **로깅** | `Logback` (SLF4J) | 유연하고 성능 좋은 로깅 프레임워크. |
| **테스트** | `JUnit 5`, `Mockito` | 단위 및 통합 테스트를 위한 표준 프레임워크. |
| **테스트 DB** | `H2 Database` | 테스트 코드 실행 시 인메모리 DB로 MySQL 대신 사용. 빠른 테스트 환경 구성. |

| **상점 기능** | 유료 식물/테마, 장식 아이템, 과금 씨앗 등 판매 |
| **확장팩** | 동물 키우기 등 새로운 게임화 요소 확장팩 개발 |
